# SYSIM

**System Integrity Manager** утилита для восстановления и администрирования Windows в одном окне.
Написана на чистом Win32 API + GDI+, без сторонних библиотек.
Собирается со статическим рантаймом (/MT), поэтому exe можно положить
на флешку и запускать прямо в среде восстановления (WinRE).

## Что умеет

### Главная
Быстрый доступ к системным инструментам и запуск команд.

- **Строка запуска** внизу окна: пути, команды, URL, `ms-settings:`-схемы.
  Enter — выполнить, Esc — отмена. Кнопки «Выполнить» и «Обзор...».
- **Питание:** перезагрузка, выключение, спящий режим, выход из системы,
  блокировка рабочего стола.
- **Консоли:** CMD, PowerShell, Терминал (Windows Terminal на Win11,
  фоллбэк на CMD на Win10) — все с повышением прав.
- **Оснастки:** диспетчер задач, редактор реестра, службы, управление дисками,
  просмотр событий, планировщик, монитор ресурсов, диспетчер устройств.
- **Восстановление:** точка восстановления (rstrui), msconfig,
  переход на вкладку «Разблокировка».
- **Настройки:** параметры Windows, панель управления, свойства системы,
  настройки самой программы.
- **Прочее:** проводник, блокнот, калькулятор, сетевые подключения,
  справка.

### Диспетчер задач
Процессы, службы, автозагрузки. Поиск, контекстные меню, ресайз колонок.
Проверка цифровой подписи исполняемых файлов, подсветка подозрительных
записей по набору эвристик.

### Проводник
Навигация по дискам, адресная строка с inline-редактированием,
контекстное меню (копировать, переименовать, удалить, создать, запуск от админа).
Текстовые файлы открываются во встроенном блокноте.

### Реестр
Просмотр и редактирование ключей и значений.
В WinRE — работа с оффлайн-кустами восстанавливаемой системы.

### Разблокировка
Модуль для восстановления системы после сбоев и повреждений:
- возврат диспетчера задач, regedit, CMD, «Выполнить», панели управления,
  контекстного меню и прочих политик;
- очистка DisallowRun и IFEO Debugger;
- восстановление Shell/Userinit, удаление баннера входа (LegalNotice);
- возврат ассоциаций EXE/BAT/CMD, сброс прокси и скрытых файлов, hosts,
  восстановление служб безопасности Windows, очистка AppInit_DLLs;
- сброс ограничений запуска приложений;
- сброс NTFS-прав (takeown + icacls);
- ремонт загрузки (bootrec / bcdboot), снятие BCD safeboot.

В WinRE всё это работает оффлайн — через загрузку кустов
SOFTWARE / SYSTEM / NTUSER.DAT восстанавливаемой системы.

### Мониторинг
Наблюдение за изменениями в системе: файлы на всех дисках, реестр, процессы,
службы и сетевые подключения. Удобно, чтобы посмотреть, что оставляет
после себя установщик или обновление. Отчёт сохраняется в файл,
события копируются в буфер обмена.

### Учётные записи
Управление аккаунтами: список, вкл/выкл, смена пароля, выдача/снятие
прав администратора, создание и удаление.
В WinRE — работа с оффлайн-аккаунтами восстанавливаемой системы
(просмотр, включение/отключение, права администратора).

### Блокнот
Встроенный редактор с вкладками: несколько документов, сохранение в исходной
кодировке (ANSI / UTF-8 / UTF-16), автоотступы, запуск .bat / .cmd / .ps1 /
.py / .exe с перехватом вывода.

### Прочее
Тёмная тема, своё оформление окна, сворачивание в трей при закрытии,
режим «поверх всех окон».

## Требования

- Windows 10/11 x64;
- Visual Studio 2022 (компонент «Разработка классических приложений на C++»);
- Windows 10/11 SDK.

## Сборка

⚠️ Для сборки требуется `WinCtrl.lib` — внутренняя библиотека, **не входящая
в репозиторий**. Без неё собрать проект нельзя.

Если библиотека у вас есть, положите её и заголовки в папку `WinCtrl/`
в корне репозитория:

```
WinCtrl/
├── include/          ← .h из приватной библиотеки
└── lib/WinCtrl.lib
```

Дальше:

1. Открыть `SYSIM.Win32GUI.sln`.
2. Выбрать конфигурацию `Release | x64`.
3. Сборка → Перестроить решение.

Готовый exe лежит в `x64\Release\`.

Если библиотеки нет — используйте готовый релиз (см. ссылку вверху).

## Использование в WinRE

1. Загрузиться с установочного носителя:
   «Восстановление системы» → «Поиск и устранение неисправностей» → «Командная строка».
2. Запустить `SYSIM.Win32GUI.exe` с флешки или диска.
3. Реестр, Разблокировка, Учётные записи и Мониторинг будут работать
   с оффлайн-системой.

Права администратора обязательны (в WinRE они есть по умолчанию).

## Структура проекта

```
SYSIM/
├── core/               # класс App, глобальные переменные, оконная процедура
├── features/           # вкладки: home, taskmgr, explorer, registry,
│                       #   unlock, monitor, accounts, notepad, settings
├── ui/                 # общий UI: сайдбар, вкладки, кнопки окна
├── utils/
│   ├── file_system/    # проводник, работа с текстовыми файлами
│   ├── registry/       # редактор реестра, автозагрузки из реестра
│   ├── process/        # процессы и службы
│   ├── startup/        # автозагрузки: папки, службы, расширения
│   ├── unlock/         # логика разблокировки (политики, IFEO, ACL, boot)
│   ├── accounts/       # управление учётными записями (online + offline)
│   └── history/        # монитор изменений
├── assets/             # встроенный шрифт
├── Resource.h          # идентификаторы ресурсов
├── SYSIM.rc            # ресурсы (иконка)
└── SYSIM.ico
```

## Дисклеймер

SYSIM убирает *последствия* сбоев и повреждений — блокировки, подмены,
политики — и помогает восстановить систему. Он не заменяет антивирус:
для поиска и удаления самих вредоносных программ используйте
специализированные оффлайн-сканеры.
